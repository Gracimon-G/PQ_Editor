PQ Editor

Unchained M Engine · Zero Locks, Zero Freezes
💡 1. Overview / 工具概述

PQ Editor is a standalone, ultra-fast Power Query (M) code editor and dependency analyzer designed for Excel workbooks (.xlsx, .xlsm, .xlsb). It reads and writes M code directly to the workbook’s internal DataMashup package without launching Microsoft Excel.

PQ Editor 是一款专为 Excel 工作簿（支持 .xlsx、.xlsm、.xlsb）设计的独立高速 Power Query (M 代码) 编辑器与依赖分析器。它直接读写工作簿内部的 DataMashup 二进制包，完全无需启动 Excel。

Why use PQ Editor? When editing M code inside Excel's native Power Query editor, Excel blocks all other workbook interactions, spins up heavy background processes, and frequently locks or freezes. PQ Editor allows instant, lightweight code editing, batch exports, visual lineage inspection, and safe atomic saves.
为什么使用 PQ Editor？ 在原生 Excel 的 Power Query 编辑器中编写代码时，Excel 会独占并锁定界面，导致其他表格无法操作甚至卡死冻结。PQ Editor 带来轻量毫秒级启动、无需打开 Excel、语法自动校验、依赖全景可视化与安全自动备份。
🚀 2. Quick Start / 快速上手

  1. Open a Workbook: Click 📂 Open… to open any .xlsx, .xlsm, or .xlsb file. The status banner displays the file name and total queries loaded.

    打开工作簿： 点击顶部工具栏的 📂 Open… 打开任意 .xlsx、.xlsm、.xlsb 文件。顶部徽标会立即显示当前加载的文件名与查询总数。

  2. Navigate Queries: The left sidebar organizes all queries by their Query Groups (Folders) (e.g. 📁 Helper Query, 📁 Other Queries) and displays their real-time Excel destination:
    • 📊 Table: Sheet!Table — Loaded to a worksheet table.
    • 🔗 Connection Only — Retained in memory without populating sheets.
    • 📈 Data Model / PivotTable — Loaded to the Power Pivot model.
    Double-click or select any query in the sidebar to jump directly to its definition in the code editor.

    定位与切换查询： 左侧导航栏根据 Excel 中的查询组文件夹（如 📁 Helper Query、📁 Other Queries）自动树形分类，并显示精确的加载目标：
    • 📊 Table: 工作表!表名 — 已加载至特定工作表表格。
    • 🔗 Connection Only — 仅创建连接，不落地工作表。
    • 📈 Data Model / PivotTable — 已加载至数据模型或数据透视表。
    单击或双击任意查询，右侧代码区会立即平滑跳转并高亮该查询定义。

  3. Edit & Validate: Edit M formulas with full syntax highlighting, synchronized line numbers, and live cursor position tracking (Ln xx, Col xx).

    代码编辑与校验： 在右侧编辑器中编辑 M 语言代码，享受完整的语法高亮、同步行号显示以及底部状态栏的实时光标行/列追踪 (Ln xx, Col xx)。

  4. Save Changes Safely: Click 💾 Save ▾ and choose Save (in place) or Save As New File…. An automatic .bak backup is created before overwriting.

    安全保存： 点击 💾 Save ▾ 下拉菜单选择 Save (in place) 或 Save As New File…。保存时系统会在同目录下自动生成 .bak 备份文件。

3.2 Pre-Save Syntax Validation / 保存前语法防护

Before writing back to the workbook, PQ Editor scans the M code for unbalanced brackets ((), [], {}), unclosed strings ("..."), unclosed quoted identifiers (#""), and unmatched let ... in blocks. If syntax errors exist, it warns you before saving and positions the cursor directly at the problematic line.

在写入工作簿前，PQ Editor 会自动运行语法平衡检测器，排查未闭合的括号（()、[]、{}）、未闭合的字符串（"..."）、带引号标识符（#""）以及缺失的 let ... in 关键字块。若发现异常会提前弹窗预警，并自动将光标定位到错误所在行，杜绝损坏 Excel 模型的风险。

3.3 File Lock & Backup Protection / 文件锁保护与备份恢复

• Locked by Excel Detection: If the file is open in Microsoft Excel, Windows places an exclusive lock on it. PQ Editor detects this and provides a friendly popup advising you to close Excel or use Save As New File….
• 1-Click Backup Restore: If you make an unwanted change, choose 💾 Save ▾ → Restore Backup from .bak to instantly revert the workbook to its previous state.

• Excel 文件占用智能提示： 当目标 Excel 文件正在被 Excel 运行时占用时，Windows 会拒绝写入。PQ Editor 会弹出友好中文/英文提示，指导您关闭 Excel 后重试或使用 Save As New File… 保存。
• 一键从备份恢复： 如代码修改有误，点击 💾 Save ▾ → Restore Backup from .bak，即可一键将工作簿无损还原到上次修改前的初始状态。

3.4 Multi-Extension Code Export / 多格式脚本导出

Under 📤 Export ▾, you can export queries as:
• Single Combined File: Exports all queries into one file (choose .pq, .m, or .txt).
• Split per Query: Creates a folder containing individual <QueryName>.pq files for clean version control (Git).

通过 📤 Export ▾ 下拉菜单，可灵活导出 M 代码：
• 合并导出为单文件： 将所有查询合并保存为一个文件（自由选择 .pq、.m 或 .txt 扩展名）。
• 拆分导出每个查询： 自动为每个查询生成独立的脚本文件（如 Query1.pq），非常适合 Git 版本控制与代码库归档。

3.5 Dark & Light Theme / 深色与浅色模式

Click the 🌙 Dark Mode / ☀️ Light Mode toggle in the top-right header to switch themes. The dark theme adopts VS Code dark palette (#1E1E1E editor, syntax highlights, and dark search/find entries).

点击右上角的 🌙 Dark Mode / ☀️ Light Mode 按钮可一键切换主题风格。深色主题采用专业 VS Code 调色板（#1E1E1E 背景、高对比度语法配色，输入框与搜索栏全面深色化适配）。

❓ 5. FAQ & Troubleshooting / 常见问题排查

Q1: "Cannot save because file is locked by Excel"

Cause: You have the same workbook open in Microsoft Excel. Windows locks open Excel files against external modification.
Solution: Either close the file in Excel and click Save again, or click Save As New File… to save your edited version under a new name.

原因： 您当前正在 Microsoft Excel 中打开着此工作簿，Windows 操作系统对打开的文件启用了独占写保护。
解决方案： 在 Excel 中关闭该表格后重新点击保存；或者选择工具栏中的 Save As New File… 保存为副本。

Q2: What is the status indicator (Ln xx, Col xx)?

Answer: Ln is the current line number (row) of your cursor, and Col is the column offset (character position on that line). It updates live as you type or move the cursor.

解答： Ln 代表光标当前所在的行号，Col 代表当前行的字符列数位置。随着按键移动光标，数值实时动态更新。

Q3: Will editing M code via PQ Editor break existing Excel data?

Answer: No. PQ Editor strictly modifies only the M query formula package inside customXml/ without altering worksheet cells, pivot caches, formulas, VBA code, or formatting. Furthermore, an automatic .bak copy is always created as a safety net.

解答： 不会。PQ Editor 仅精确重写 customXml/ 目录下的 M 语言公式包，完全不会触碰工作表单元格、数据透视表缓存、单元格公式、VBA 代码或格式排版。且每次写入均有同名 .bak 文件兜底保障。
